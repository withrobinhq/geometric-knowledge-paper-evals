## Execution status

- The Dimension term, standing penalty, Domain scoping and HyDE escalation were scored on recovered values.
- Retrieval arms (i) to (viii) were registered.
- Arm (ix), facet-only, was evaluated post hoc.
- The other fifteen registered components are not reported as scored.
- The public release contains the surviving summary record. Some underlying run artifacts are unavailable.

See `execution_record.yaml`, `pilot/` and `results/`.

## Public companion

- `pilot/calibration.csv`, `pilot/peps.csv` and `pilot/enron.csv` contain pseudonymous A/B judgments.
- `pilot/protocol.yaml` and `pilot/provenance.yaml` describe the pilot and sources.
- `pilot/pilot_results.csv` contains the reproduced pilot metrics.
- `results/` contains the pooled retrieval summaries and descriptive pilot validity table reported by the paper.

Raw source downloads, superseded runs, caches and private annotator names are not included.
